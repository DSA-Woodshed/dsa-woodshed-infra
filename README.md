# dsa-woodshed-infra

Reserved implementation overlay for The DSA Woodshed's future
remote-everything setup (runner registration, shared caches, apply
planes), following the overlay-not-ownership pattern: application
repositories stay where they are, and this repository will hold only
operator-owned infrastructure configuration.

Empty by design. Population is gated on the operator's infrastructure
milestones; nothing here is load-bearing yet.
